## About

I focus on building apps that work beyond demos: authentication, offline sync, local caching, crash reporting, dashboards, PDF/reporting flows, background jobs, and app-store-ready Android builds.

My strongest work sits around Flutter, Firebase, offline-first architecture, business operations tools, and mobile products that need reliable day-to-day use.

## Core Strengths

- **Mobile engineering:** Flutter, Dart, Android release builds, native integrations, app permissions, and platform channels.
- **Firebase systems:** Auth, Firestore, Storage, App Check, Crashlytics, Remote Config, Performance Monitoring, and security rules.
- **Offline-first architecture:** local persistence, cache-first reads, queued writes, background sync, and resilient field workflows.
- **Product delivery:** clean UX, dashboards, reports, release preparation, documentation, and production hardening.
- **AI and automation:** on-device AI experiments, Python pipelines, MLOps structure, and practical developer tooling.
