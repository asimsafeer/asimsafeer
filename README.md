# Hi, I'm Aasim Safeer

Flutter app developer focused on production mobile systems, Firebase-backed workflows, offline-first architecture, and practical AI tooling.

I build apps that are meant to survive real users: authentication, caching, background sync, crash reporting, release builds, admin dashboards, and field-ready UX for businesses.

## What I Build

- **Flutter + Firebase apps** with auth, Firestore, Cloud Storage, Crashlytics, Remote Config, and Play Console release readiness.
- **Offline-first business tools** with local caching, durable write queues, background sync, and conflict-aware data flows.
- **Mobile productivity apps** with native Android integrations, local databases, permissions, and polished app-store surfaces.
- **AI and automation projects** that turn models, notebooks, and scripts into usable workflows.
